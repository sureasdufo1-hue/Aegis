## 1. 보고서 요약 (Executive Summary)

보안관제센터(SOC)의 본질은 보안 소프트웨어를 단순히 많이 설치하는 외형적 확장에 있지 않습니다. 선로 상에서 흐르는 네트워크 패킷을 누락 없이 들여다보고, 정상 업무 트래픽을 해킹으로 잘못 의심하는 **'오탐(False Positive)'을 근본적으로 제거하면서도, 실제 침투 공격만을 100% 잡아낼 수 있는 정밀한 탐지 통제력**을 확보하는 것이 핵심입니다.

Aegis 프로젝트는 이러한 보안관제의 기본이자 핵심을 엔지니어링 수준에서 입증하기 위해 출발했습니다. 가상화 인프라 환경에 3개의 물리적 분리망을 구축하고, 주소가 없는 스텔스 센서(Promiscuous mode)로 패킷 가시성을 확보한 뒤, **수리카타(Suricata 8.0.6)**와 **스노트(Snort 3.12.2.0)** 듀얼 침입탐지 엔진, **와주(Wazuh 4.14.7)** 통합 보안 로그 분석 시스템, 자체 개발한 **30분 슬라이딩 윈도우 기반 킬체인 상관분석 엔진**, 그리고 오차단을 원천 방어하는 **4중 보안 가드레일 기반 로컬 인공지능(AI) 관제 콘솔**을 완벽히 연동했습니다.

## 3. Aegis 보안관제의 8대 핵심 기술 혁신 축

1. **듀얼 침입탐지(Suricata 8 + Snort 3) 역할 분담**: 실시간 고속 인라인 탐지(Suricata AF_PACKET)와 오프라인 PCAP 교차 재검증(Snort 3 DAQ)을 분리하여 벤더 중립적 교차 검증 체계 완성.
2. **Wazuh 4.14.7 부모 룰 선점 버그 원천 해결**: EVE JSON 로그를 내장 디코더 룰(`86601`)이 가로채던 결함을 `<if_sid>86601,100100</if_sid>` 복합 선언으로 복구하여 호스트-네트워크 이벤트 체이닝 완성.
3. **호스트-네트워크 다계층 교차 상관분석**: L4 TCP 포트 스캔(`Rule 100103`)과 리눅스 PAM 인증 실패(`Rule 5710/5716`) 및 성공(`Rule 5715`)을 결합하여 `Level 14 Critical` 계정 탈취 즉시 승격.
4. **RAG 기반 로컬 AI Copilot & 4중 가드레일**: 외부 인터넷 유출 없는 완전 오프라인 Ollama 로컬 LLM(Qwen 2.5 7B)과 4중 안전 가드레일(인젝션 방어, 툴 화이트리스트, Fail-Closed, HITL 2단계 승인) 탑재.
5. **Detection-as-Code (DaC) CI/CD 린터**: GitHub Actions와 자체 룰 린터(`scripts/validate_rules.py`)로 82개 룰셋(Suricata 47, Snort 28, Wazuh 7)의 문법 무결성을 전수 자동 검증 (Errors: 0).
6. **SOAR 실시간 멀티채널 알림 디스패처**: Slack Block Kit, Discord Embed, Webhook으로 격리 명령어가 포함된 조치 중심 알림을 전파하고, 10분 쿨다운 및 진단 텔레메트리 억제로 관제 피로도 완벽 차단.
7. **Nginx SSL Termination 기반 TLS 1.3 복호화**: HTTPS 암호화 트래픽을 인바운드 프록시에서 복호화해 Suricata에 평문 L7 가시성을 제공하고, 외부 C2는 패시브 SNI/인증서 검사로 적발 (`ARCH-TLS-001`).
8. **GitHub Pages 실시간 인터랙티브 웹 쇼케이스**: 채용 담당자와 기술 면접관이 로컬 설치 없이 15단계 파이프라인과 23대 면접가이드를 실시간 검색할 수 있는 모던 웹 포트폴리오 공개 배포.
