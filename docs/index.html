Interview Technical Defense Guide

기술 면접 방어 가이드 23선 (인터랙티브 검색)

SOC 리드 및 보안 아키텍트 면접관의 고난도 질문에 대응하는 실측 근거 기반 답변집

🔍
엔터프라이즈 환경에서는 외부 위협 구역과 내부 서버, 관리망이 엄격히 망분리되어야 합니다. 본 랩은 단일 호스트 내에서 3개의 가상 스위치를 구성하고, 공격망에서 관리망으로의 통신을 게이트웨이 nftables의 DEFAULT DROP 정책으로 원천 차단하여 물리 망분리에 준하는 격리를 구현했습니다.
공격 표면의 원천 제거: 센서 인터페이스에 IP가 있으면 공격자가 역스캔으로 IDS 존재를 식별하거나 타깃 DoS/RCE 공격을 가할 수 있습니다. L3 IP가 없으면 커널이 ARP나 ICMP를 일절 전송하지 않아 공격자가 탐지 장비의 존재를 전혀 눈치챌 수 없는 스텔스 센서(Stealth Sensor)가 완성됩니다.
패킷이 미러링되지 않는 상태에서 상위 IDS나 SIEM을 구축하는 것은 무의미합니다. 본 랩은 Attacker에서 Victim으로 제어된 ICMP 핑을 발송하고, 센서의 모니터링 NIC에서 tcpdump로 양방향 패킷이 무손실 수신되는 것을 직접 확인한 뒤에야 GATE-NET-01 PASS를 승인하고 Suricata 설치를 시작했습니다.
2단계 전략: 1) 인바운드 웹 공격은 Nginx SSL Termination 리버스 프록시 후단 평문 미러링을 통해 L7 HTTP 페이로드(SQLi, XSS)를 100% 검사(ARCH-TLS-001). 2) 외부 C2 역접속 등 복호화가 불가능한 트래픽은 핸드셰이크 단계의 SNI 도메인(tls.sni) 및 인증서 Subject(tls.cert_subject) 메타데이터로 탐지합니다.
Wazuh 기본 Suricata 룰 86601은 no_full_log 옵션으로 인해 하위 커스텀 룰 작성 시 alert.signature_id 필드가 상속되지 않아 이벤트가 증발하는 치명적 결함이 있습니다. 본 랩은 부모 룰 100100을 신설하여 86601을 명시적 상속하고 필드 추출 정규식을 오버라이드하여 전 파이프라인 색인을 복원했습니다.
1) 사내 표준 룰북만 검색하는 RAG 제한, 2) 게이트웨이/DNS/SIEM IP를 강제 보호하는 Protected Assets 필터, 3) AI의 단독 실행을 금지하고 관제 요원의 수동 승인을 거치는 HITL(Human-in-the-Loop) 승인 큐, 4) 결정론적 Temperature 0.1 고정으로 AI의 자의적 오차단을 100% 방지합니다.
GitHub Actions 워크플로우(.github/workflows/ci.yml)와 자체 린터(scripts/validate_rules.py)를 구축했습니다. Suricata 47개, Snort 28개, Wazuh 7개 총 82개 룰에 대해 SID 할당 범위(9000~9099 / 9100~9199), 중복 SID, 필수 태그(msg, sid, rev, description)를 커밋 시 자동 검증하여 운영 무결성을 보장합니다.
Level 14 Critical(계정 탈취, C2 비콘) 발생 시 Slack Block Kit, Discord Embed, Webhook으로 즉시 전파됩니다. 메시지에는 초동 조치용 방화벽 격리 명령어(nft add element ...)가 동봉됩니다. 또한 동일 IP에 대해 10분 슬라이딩 윈도우 쿨다운과 단순 Ping 등 비위협 진단 트래픽 억제 필터를 적용하여 관제 요원의 경보 피로도를 방지합니다.
soc-reverse-proxy(Nginx 1.27) 컨테이너가 443(HTTPS)을 수신하여 TLS 1.3을 복호화하고 백엔드 웹서버로 평문 HTTP를 전달합니다. Suricata는 후단 미러링을 통해 평문 L7 패킷을 검사하여 SQL Injection(SID 9010001)을 100% 정상 발화합니다. 외부 C2 트래픽은 패시브 핸드셰이크 검사(SID 9030025, 9030026)를 병행하여 다계층 가시성을 실증했습니다.
